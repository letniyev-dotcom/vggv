# Мимика

Минималистичное мобильное приложение — привычки и план на день,
без карточек, без лишнего визуального шума. Единый концепт: один экран
отвечает на один вопрос «что делать прямо сейчас», всё остальное (история
привычки, сон/вес/вода/питание) — на расстоянии одного тапа.

Собрано на Kotlin + Jetpack Compose, по прототипу `mimika-unified-concept.html`.

## Экраны

1. **Главный экран** — «День N», привычки за неделю (тап → детально),
   таймлайн задач на сегодня, тихая ссылка на «Дневник» внизу.
2. **Привычка · детально** — месячная сетка вместо пустого кольца, список
   остальных привычек для быстрого переключения.
3. **Дневник** — сон, вес, вода, питание.

## Что перенесено из Letify «как есть»

- **Анимация перехода «Сдвиг»** (`ui/nav/ShiftNav.kt`) — тот же easing
  (`CubicBezier(0.32, 0.72, 0.0, 1.0)`) и та же длительность (360ms), что и
  push-переход в Letify: уходящий и приходящий экран движутся одной
  непрерывной лентой. Реализовано через Compose `AnimatedContent` (не через
  ручной `pointerInput`, как в Letify) — тот же визуальный результат, меньше
  риска сборки без реального устройства для теста.
- **Кастомный эластичный оверскролл** (`ui/components/ElasticOverscroll.kt`)
  — портирован из Letify практически без изменений (только смена пакета).
  Системный Android-стретч отключён (`LocalOverscrollConfiguration provides
  null`), вместо него — iOS-подобный rubber-band с пружинным возвратом.
- **Прозрачный статус-бар** — edge-to-edge, контент буквально проезжает под
  иконками статус-бара при скролле вверх.

## Локальная сборка

```bash
./gradlew :app:assembleRelease
```

APK появится в `app/build/outputs/apk/release/app-release.apk`.

Подписан коммитнутым dev/CI-ключом `app/mimika-release.jks`
(`storePassword`/`keyAlias`/`keyPassword` = `mimika`) — этого достаточно,
чтобы APK сразу ставился на устройство. Это **не** ключ для публикации в
Google Play — перед реальным релизом в сторе замените keystore и
`signingConfig` в `app/build.gradle.kts` на свой продакшн-ключ.

## Автоматическая сборка в GitHub Actions

`.github/workflows/release.yml` при каждом push/PR собирает **только
релизный APK** (`assembleRelease`, debug-сборки нет вообще) и прикладывает
его как workflow-артефакт — зайти во вкладку **Actions** → выбрать последний
запуск → скачать `mimika-release-apk` внизу страницы.

Если запушить тег вида `v1.0.0`:

```bash
git tag v1.0.0
git push --tags
```

— воркфлоу дополнительно создаст GitHub Release с APK, прикреплённым к
релизу, для скачивания в один клик без захода в Actions.

## Структура проекта

```
app/src/main/java/com/mimika/app/
├── MainActivity.kt
├── data/MockData.kt          — мок-данные экранов (привычки, задачи, дневник)
└── ui/
    ├── components/           — переиспользуемые composable (без карточек)
    ├── nav/ShiftNav.kt        — переход «Сдвиг»
    ├── screens/               — HomeScreen, HabitDetailScreen, DiaryScreen
    └── theme/Theme.kt         — цвета/типографика из концепта
```
